# Quickstart de Validação

Após Implement: `pnpm install`, configurar `.env` a partir de `.env.example`, executar migration local e `pnpm dev`.

Executar: `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm test:integration`, `pnpm test:e2e`, `pnpm build`.

Validar cadastro PROFESSOR, bootstrap ADMIN controlado, login genérico em falhas, rota privada, múltiplas sessões, logout atual, refresh rotativo, conta inativa, rate limit, CORS `WEB_ORIGIN` e auditoria sem segredos.
